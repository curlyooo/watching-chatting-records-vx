# watching-chatting-records-vx

微信聊天记录读取工具（最小版本）。

适用于 PC 微信 4.x（已在 4.1.15 上测试），浅色主题。

## 原理

微信 4.x 的窗口不对外暴露控件，所以用截图加文字识别：

1. 截取微信窗口的画面。窗口被遮挡也能截，但不能最小化。
2. 按颜色找出聊天气泡：绿色是你发的，浅灰是对方发的。
3. 用 RapidOCR 识别聊天区文字。这是本地开源的中文识别，比 Windows 自带的准确得多；没装时会退回自带识别。
4. 文字落在哪个气泡里就是哪条消息的正文。气泡外的灰字按位置判断：
   - 气泡正上方的是昵称。
   - 气泡正下方、形如"昵称：内容"的是引用。
   - 居中的是时间分隔。
5. 逐格发送滚轮消息往上翻页，每次约半屏，相邻两屏按重叠的消息去重拼接。被屏幕边缘截断的消息留给下一屏补全。
6. 抓完自动滚回聊天最底部。

工具只读：不点击、不输入、不发送消息，也不读取微信的数据文件。识别全程在本地完成。

## 安装

```
pip install -r requirements.txt
```

## 用法

先在微信里打开要抓的聊天，然后运行：

```
python wxread.py --days 1 --screens 30
```

- 遇到早于 `--days` 的时间分隔，或翻满 `--screens` 屏，就停止。
- 每屏约 2.5 秒。活跃的群一屏只有几分钟的消息，抓一整天可能需要上百屏。
- 把微信窗口拉高（最好最大化），一屏能放下更多消息，翻页距离也会按高度自动加大，总屏数更少。
- 抓取期间不要操作微信窗口，也不要最小化它。

结果保存在 `output/` 下，每次生成一份 `.md` 和一份 `.json`。

## 实测（群聊，20 屏）

- 拼接出 92 条，两屏之间没有漏拼。
- 3 条发送人未知，记为 `?`。
- 1 条短消息未识别。

## 已知限制

- 图片、表情、语音暂不记录。文件卡片能记下文件名。
- 极短的消息偶尔识别不出，记为"[短消息未识别]"。
- 只支持浅色主题。
- 时间分隔是微信自己生成的，会随时间重新排布，所以每条消息的时间只精确到所在的分隔段。
